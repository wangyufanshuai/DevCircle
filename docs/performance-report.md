# v1.0 压测报告模板

> 当前版本提供 k6 脚本和报告模板。用户要求先完成短板实现、跳过最终统一测试，因此本地与云服务器实测数据会在统一测试阶段补录。

## 脚本

```bash
k6 run tests/k6/mysticverse-smoke.js
```

可配置参数：

```bash
BASE_URL=http://localhost:8080 VUS=20 DURATION=3m k6 run tests/k6/mysticverse-smoke.js
```

覆盖链路：

- 推荐 Feed
- 搜索
- 帖子详情
- 点赞幂等
- 推理解谜提交

## 预期优化方向

- Feed 候选召回增加本地缓存与异步刷新。
- 搜索接口增加热门关键词缓存。
- Outbox publisher 做批量发送和失败分级告警。
- 媒体上传增加对象存储直传，降低应用服务带宽压力。
